## Contexte
Spec 13, fichier 04, R15 : le statut vient du profil ; classement proposé, jamais un calcul de paie. Président de SAS : paie externe importée (641100 / 421000, charges 645100 / 431000) ; gérant majoritaire de SARL : 641100 / 421000, cotisations lues sur les appels ; EI : prélèvement de l'exploitant en 108000, aucune charge. Comptes « à vérifier » dans le plan du millésime. Tests MOT87-1 (brut 3 000,00, retenues 660,00, net 2 340,00, charges 1 260,00), MOT87-2 (EI 1 500,00), MOT87-3 (gérante 2 000,00).

## À faire
1. `packages/noyau/src/dirigeant/remuneration.ts` (types de `../ecritures/modele.js`) :
   - `proposerRemuneration(statut (president_sas, gerant_majoritaire_sarl, exploitant_ei), donnees, comptes, ctx { idBase; date; journal })` donne une liste d'écritures `brouillon` ;
   - président : `{ brut; retenues; net; chargesPatronales }` ; brut différent de net + retenues : `ErreurDirigeant('paie_incoherente')` ; écriture 1 : D remuneration brut / C personnel net / C organismes retenues ; écriture 2 (si charges non nulles) : D chargesSociales / C organismes ;
   - gérant : `{ remuneration }` : une écriture D remuneration / C personnel ; aucune cotisation calculée ;
   - exploitant : `{ prelevement }` : D exploitant / C banque ; aucune charge ;
   - statut inconnu : `statut_dirigeant_inconnu` ; montant négatif, NaN ou non entier : `montant_invalide`.
2. Tests nommés (comptes de la spec passés en argument) : `president-paie-importee` (MOT87-1), `exploitant-prelevement-sans-charge` (MOT87-2), `gerant-sans-calcul-de-cotisation` (MOT87-3 : une écriture, deux lignes), `paie-incoherente-refusee`, `charges-nulles-une-seule-ecriture`, `statut-inconnu-refuse`, `montants-invalides` (−1, NaN, 1,5, Infinity).
