## Contexte
Spec 13, fichier 02, R18 : toute fonction, canal, connecteur ou envoi nouveau a un interrupteur créé fermé. R20 : passage fermé, puis pilote (interne) pendant une durée pleine (7 jours dans le registre), puis geste d'une personne habilitée avec motif ; passage direct refusé ; retour à fermé immédiat. Test PRI-13-02 : pilote le 06/11 à 09:00 ; demandes le 10/11 et le 13/11 à 08:59 refusées, le 13/11 à 09:00 acceptée. Cas limite : le retour à fermé annule les envois en file non partis ; ceux déjà partis sont listés.

## À faire
1. `packages/noyau/src/principes/interrupteurs.ts` (instants en millisecondes entières, aucune date locale) :
   - `EtatInterrupteur { code; etat (ferme, pilote, ouvert); depuis: number }` ; `creerInterrupteur(code, maintenant)` donne un état fermé ;
   - `demanderTransition(etat, cible, ctx { maintenant; dureePiloteMs; acteur { type (personne, service, agent, tache); habilite }; motif? })` donne le nouvel état ou un refus `{ ok: false; code }` : `passage_direct_interdit` (fermé vers ouvert), `pilote_trop_court` (maintenant moins depuis, strictement inférieur à la durée), `geste_requis` (vers pilote ou ouvert sans personne habilitée), `motif_obligatoire` (vers ouvert, motif vide ou blancs), `deja_dans_cet_etat`, `horloge_incoherente` (maintenant antérieur à depuis) ; vers fermé : toujours accepté, quel que soit l'acteur ;
   - `envoisAuRetourFerme(file: { id; parti }[])` donne `{ annules; dejaPartis }` (listes d'ids triées).
2. Tests nommés (durée passée en argument : 7 × 86 400 000 ms, exemple du registre) : `ferme-par-defaut`, `passage-direct-refuse`, `pilote-duree-pleine` (les 3 instants de PRI-13-02 en millisecondes UTC), `retour-ferme-immediat` (même par une tâche), `ouverture-exige-personne-et-motif`, `horloge-incoherente`, `entrees-invalides` (NaN, Infinity, durée négative ou 1,5), `retour-ferme-annule-la-file`.

## Hors périmètre
Pas de table `interrupteur`, pas de route d'ouverture (persistance bloquée : L13-T47). La garde `garde:interrupteurs` existante (registre des actions) n'est pas modifiée.
