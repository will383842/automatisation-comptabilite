## Contexte
Spec 15, fichier 05 : `catalogue_liste_exportable` contient TOUTES les listes du contrat ; « une route de liste sans ligne ici fait échouer la CI ». Un catalogue écrit à la main obligerait chaque fiche de chaque lot qui ajoute une liste à toucher ce fichier (conflits, fiches refusées par la garde de périmètre). Choix : le catalogue est CALCULÉ depuis le contrat. Toute nouvelle liste est exportable sans toucher ce fichier, et ses colonnes texte passent par la neutralisation (L15-T04).

## À faire
1. `packages/contrat/src/exports/catalogue.ts` :
   - type `TypeColonne = 'texte' | 'entier' | 'centimes' | 'date' | 'booleen'` ; `ColonneExport { code; type }` ; `ListeExportable { code (operationId); methode; chemin; colonnes: ColonneExport[]; colonneTotal?: string }` ;
   - `catalogueExportable(contrat)` : parcourt récursivement l'objet contrat (toutes les clés, présentes et futures), lit `['~orpc'].route` et le schéma de sortie, garde les routes `GET` dont la sortie est une enveloppe `{ body: tableau d'objets, ... }` ; colonnes lues par `z.toJSONSchema` (zod 4) sur l'objet ligne ; règle : `integer` dont le nom finit par `Centimes` = `centimes`, autre `integer` = `entier`, `boolean` = `booleen`, chaîne au motif AAAA-MM-JJ ou au format `date` = `date`, TOUT le reste (chaîne, énumération, objet, tableau, inconnu) = `texte` (le plus prudent : neutralisé) ; `colonneTotal` = première colonne `centimes` s'il y en a une ;
   - `colonnesTexte(catalogue)` : couples `{ liste, colonne }`.
2. Tests nommés : `contient-plan-tiers-ecritures`, `routes-non-liste-exclues` (POST, PUT, réponse sans tableau), `centimes-par-suffixe`, `inconnu-devient-texte` (union, objet imbriqué, `z.any()`), `catalogue-suit-le-contrat` (contrat forgé avec une route de liste de plus : elle apparaît sans rien écrire au catalogue), `ordre-stable` (trié par code), `liste-sans-colonne-refusee` (objet ligne vide : erreur explicite).

## Hors périmètre
Pas d'écriture de fichier (L15-T22, L15-T24), pas de route d'export (L15-T39), pas de libellés de colonnes.

## Pièges
Ne modifier ni `routes.ts` ni un domaine existant. Aucun champ d'un autre lot ne doit faire échouer la CI : un type inconnu devient `texte`, jamais une erreur. Sensible (exports) : relecture Opus.
