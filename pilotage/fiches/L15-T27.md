## Contexte
Spec 15, fichier 03, table des clés et PR-R1, PR-R4, PR-R8. Clés permises : `menu_etat` (`ouvert`, `reduit`), `chat_etat` (`reduit`, `normal`, `elargi`, `plein`), `chat_largeur_pct` (entier de 20 à 50, ramené à la borne), `mode` (`simple` par défaut, `comptable`), `raccourcis` (`{ actifs; remap: { action: lettre } }`), `resume_email` (`{ actif; heure: "HH:MM" }`), `notif_categories` (parmi `a_valider`, `echeance`, `urgent`, `cabinet`), `usage_mesure` (`active`, `desactivee`), `premier_lancement` (`{ termine }`). Clés de disposition (`menu_etat`, `chat_etat`, `chat_largeur_pct`) par type d'appareil (`bureau`, `mobile`), les autres `tous`. Clé inconnue ou valeur hors liste : 400 `preference_invalide`. `format_nombre` : 400 `format_fixe` (point P1 : le choix « point » est retiré). Raccourcis : une lettre a-z par action, sans doublon, sans lettre réservée (400 `raccourci_invalide`).

## À faire
1. `preferences/valider.ts` :
   - `validerPreference(cle, valeur, appareil)` → `{ cle; valeur (normalisée); appareil }` ou `ErreurPreference { code }` ; appareil incohérent avec la clé (`tous` pour une clé de disposition, `bureau` pour `mode`) = `preference_invalide` ;
   - `chat_largeur_pct` : entier hors bornes ramené à la borne ; non entier, `NaN`, infini, chaîne = `preference_invalide` (jamais ramené) ;
   - `resume_email.heure` : `HH:MM` de 00:00 à 23:59 ; `24:00`, `7:30`, `07:60` refusés ;
   - `notif_categories` : sans doublon, éléments de la liste ;
   - raccourcis : `lettresReservees` est un argument (liste fournie par l'appelant) ; lettre en majuscule, chiffre, deux lettres, doublon = `raccourci_invalide` ;
   - objets : toute propriété en trop = `preference_invalide` (pas de champ caché stocké).
2. Tests nommés : `cle-inconnue-refusee`, `format-nombre-format-fixe`, `menu-etat-par-appareil`, `appareil-incoherent-refuse`, `largeur-ramenee-a-la-borne` (10 donne 20, 80 donne 50), `largeur-non-entiere-refusee` (`33.5`, `NaN`, `Infinity`, `'30'`), `heure-resume-bornes`, `categories-doublon-refusees`, `raccourci-doublon-ou-reserve-refuse`, `raccourci-majuscule-ou-chiffre-refuse`, `propriete-en-trop-refusee`.
