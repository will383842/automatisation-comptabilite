## Contexte
Spec 04, fichier 02 §Typologie : 13 types, chacun « compté » ou non par défaut avec un motif. « Le type est proposé par le lecteur A, confirmé par des règles en code (mots-clés "avoir", "credit note", "acompte", "relevé", montant négatif, TTC nul). Désaccord = a_verifier. […] une pièce non comptée n'entre dans aucune somme, ni dans la TVA. » IMP-036 : PDF de plusieurs factures = À vérifier, 0 écriture. Cas T-LEC-10, 13, 14, 15.

## À faire
1. `packages/noyau/src/pieces/classement/mots-cles-types.ts` : `MOTS_CLES_TYPES = { version: 1, avoir: [...], acompte: [...], releve: [...], commande: [...], devis: [...], contrat: [...], reservation: [...], rappel: [...] }` FR et EN, minuscules sans accents (ex. `avoir`, `credit note` ; `acompte`, `down payment` ; `releve de compte`, `statement of account` ; `bon de commande`, `purchase order` ; `devis`, `quotation`).
2. `packages/noyau/src/pieces/classement/typologie.ts` :
   - `compteeParDefaut(type)` → `{ comptee: true }` ou `{ comptee: false; motif: MotifNonComptee }` selon le tableau de la spec (facture, facture_acompte, recu, ticket, avoir, reemise : comptées ; annulee, montant_zero, releve_fournisseur → `releve`, plusieurs_factures, inconnu : non ; facture_dans_corps : non, motif `a_verifier` ; non_piece : motif passé en argument parmi commande, contrat, reservation, rappel, devis, autre) ;
   - `typeParRegles({ texte, ttc?, ht?, nombreDeNumerosDeFacture })` → `TypePiece | null` : plus d'un numéro de facture = `plusieurs_factures` ; mot-clé avoir ou ttc < 0 = `avoir` ; acompte ; relevé ; commande, devis… = `non_piece` ; ttc = 0 et ht = 0 = `montant_zero` ; sinon `null` (pas d'avis) ;
   - `confirmerType(propose: TypePiece, indices)` → `{ type: TypePiece; aVerifier?: 'desaccord_type' | 'ttc_nul_ht_non_nul' | 'plusieurs_factures'; motifNonPiece? }` : règle `null` → proposé gardé ; règle = proposé → confirmé ; sinon type proposé gardé et `desaccord_type` ; ttc = 0 et ht ≠ 0 → `ttc_nul_ht_non_nul`.
3. Tests nommés : `facture-confirmee`, `avoir-par-mot-cle`, `avoir-par-montant-negatif`, `desaccord-a-verifier`, `bon-de-commande-non-piece-non-compte`, `trois-factures-plusieurs-factures`, `montant-zero-et-ttc-nul-ht-non-nul`, `table-comptee-complete` (les 13 types ont une réponse), `texte-vide-garde-le-propose`.
