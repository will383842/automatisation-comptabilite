## Contexte
Spec 05, fichier 08 §5 (REP-027) : un rédacteur et un vérificateur ; TOUT nombre du texte existe dans le registre des constats ; limites en première page ; mention « ni audit légal ni certification » ; fichier 06 §5 : « Préparé par IA, à valider » tant qu'une personne n'a pas validé.

## À faire
1. `packages/noyau/src/agents/verificateur-rapport.ts` :
   - `extraireNombres(texte)` → entiers en centimes ou entiers simples, formats français : « 12 000 », « 12 000,50 », espace insécable U+00A0 et U+202F, « -1 250,00 », « 1 250 € » ; une date AAAA-MM-JJ ou JJ/MM/AAAA est extraite comme date, pas comme nombre ;
   - `verifierRapport({ pages: string[]; marqueurs: string[] }, registre: { nombres: readonly number[]; dates: readonly string[] }, { marqueursObligatoires })` → `{ valide: boolean; inconnus: string[]; marqueursManquants: string[] }` ; les marqueurs obligatoires (codes passés en argument, par ex. `mention_ia_a_valider`, `ni_audit_ni_certification`) doivent être sur la PREMIÈRE page ;
   - aucun texte affiché dans ce module.
2. Tests nommés : `rapport-valide`, `nombre-inconnu`, `format-francais-avec-espaces-insecables`, `negatif`, `decimale-sur-un-chiffre` (« 12,5 » = 1250 centimes), `date-pas-un-nombre`, `marqueur-absent`, `marqueur-seulement-en-page-deux`, `rapport-vide` (aucune page = invalide), `nombre-geant` (au-delà de `Number.MAX_SAFE_INTEGER` = inconnu, jamais arrondi).
