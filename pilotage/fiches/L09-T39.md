## Contexte
Spec 09, §01 et §04 règle 5 : chaque champ garde son lien « voir la source » (pièce, page, zone) ; la confiance est un MOT (`sur`, `a_verifier`, `douteux`), jamais un pourcentage ; un champ « à confirmer » se voit. Style de la console (D5) : 14 px, graisse 600 au plus, aucun bleu, clair ; jetons de L01-T27.

## À faire
1. `packages/ui/src/composants/ChampSource.tsx` : props `{ intitule: string; valeur: ReactNode; statut: 'confirme' | 'a_confirmer' | 'vide' | 'je_ne_sais_pas'; confiance?: 'sur' | 'a_verifier' | 'douteux'; source?: { href: string; libelle: string } | null; libelles: { statut: Record<...>; confiance: Record<...>; voirLaSource: string; vide: string } }` (tous les textes en props : aucun texte en dur) ;
   - structure `<div role="group" aria-labelledby>` ; intitulé ; valeur (ou `libelles.vide`) ; `Pastille` (L01-T29) du statut ; confiance en mot ; lien « Voir la source » seulement si `source` est donné, `href` limité à un chemin relatif ou `https:` (sinon pas de lien) ;
   - `champ-source.css` : variables des jetons seulement (aucune couleur en dur).
2. Tests nommés (Testing Library) : `affiche-valeur-et-intitule`, `statut-annonce`, `confiance-en-mot` (aucun `%` rendu), `lien-source-present`, `sans-source-pas-de-lien`, `href-dangereux-ignore` (`javascript:alert(1)`, `data:text/html,x`, chaîne vide), `valeur-vide-libelle-vide`.

## Hors périmètre
Pas d'appel réseau, pas d'écran (L09-T41).

## Pièges
`garde:couleurs` refuse toute couleur hors jetons ; `garde:textes` refuse un texte en dur dans un `.tsx`. Ne pas modifier `composants.css` (L01-T29) ni `index.ts` de `packages/ui` : import par chemin.
