## Contexte
Spec 04, fichier 03 §4 : la `confiance_interne` (0 à 100) est « calculée par le code, jamais reprise du modèle », selon 6 situations (XML ; accord sur texte du PDF ; accord sur OCR ; A seul ; vision seule ; désaccord ou citation introuvable ou contrôle échoué). « Seuil : 85 (paramètre). Au-dessus : sur ; en dessous : a_verifier ; sous 50 : douteux. […] Confiance de la pièce = celle de son champ critique le plus faible. […] Jamais de classement automatique sous le seuil. » Valeurs du barème et seuils : arguments (réglage produit, jamais dans le code).

## À faire
1. `packages/noyau/src/pieces/lecture/confiance.ts` :
   - `BaremeConfiance { xml; accordTextePdf; accordOcr; aSeul; visionSeule; echec }` et `SeuilsConfiance { sur; douteux }` : entiers de 0 à 100, `douteux < sur`, sinon `ErreurPiece('reglage_invalide')` ;
   - `situation({ source, accord, citationRetrouvee, controlesPasses })` → clé du barème : `echec` dès que `accord === 'desaccord'`, citation introuvable (lecteur A) ou contrôle échoué ; `xml` si source `xml` ; `accordTextePdf` / `accordOcr` si accord ; `aSeul` si `seul_a` ; `visionSeule` si source `vision` sans accord ; `seul_b` = `aSeul` ;
   - `confianceInterne(entree, bareme)` → nombre ; `motDeConfiance(valeur, seuils)` → `'sur'` (>= sur), `'douteux'` (< douteux), sinon `'a_verifier'` ;
   - `confiancePiece(champs: { nom; mot }[])` → mot du champ critique le plus faible (`douteux` < `a_verifier` < `sur`) ; aucun champ critique présent = `'douteux'` ;
   - `classementAutomatiquePermis(champs)` : vrai seulement si tous les champs critiques sont `sur` et qu'il y en a au moins un.
2. Tests nommés (barème et seuils inventés dans le test) : `xml-donne-bareme-xml`, `accord-pdf-et-ocr`, `desaccord-donne-echec`, `citation-introuvable-donne-echec`, `mots-aux-bornes` (valeur = sur → sur ; sur − 1 → a_verifier ; douteux − 1 → douteux), `piece-prend-le-plus-faible-critique`, `champ-non-critique-ignore-pour-la-piece`, `aucun-critique-douteux`, `reglage-invalide-refuse` (douteux >= sur, 101, -1, NaN, 1.5).
