## Contexte
Spec 14, `03`, JUR-003. Formes à délai légal : `date_limite = date_assemblee − délai` (paramètre `jur.convocation.delai_sarl_jours`, décompte `jur.convocation.decompte`, À VÉRIFIER). Formes à délai statutaire : délai saisi depuis les statuts ; absent = pas de date, carte « Saisissez le délai prévu par vos statuts », jamais de valeur par défaut. Associé unique : non applicable. Règle 2 : rappel avant la date limite, AVANCÉ au jour ouvré précédent s'il tombe un jour non ouvré ; assemblée déplacée = tout recalculé, ancienne date gardée. Règle 3 : envoi réel après la date limite = carte « convocation tardive », rien n'est bloqué. Règle 4 : assemblée trop proche = première date possible proposée. Test C1.

## À faire
1. `packages/noyau/src/juridique/convocation.ts` (classe locale `ErreurConvocation`) :
   - `interface Calendrier { ajouterJours(date: string, n: number): string; estOuvre(date: string): boolean }` injecté (aucune arithmétique de date ici) ;
   - `RegleConvocation { formesDelaiLegal: readonly string[]; formesDelaiStatuts: readonly string[]; formesAssocieUnique: readonly string[]; delaiLegalJours: number; decompte: string; joursAvantRappel: number; maxRecul: number }` ; seul le décompte `calendaires` est traité : autre valeur = refus `decompte_non_traite` ;
   - `convocation({ forme; dateAssemblee; delaiStatutsJours: number | null; dateEnvoiReelle: string | null; aujourdhui }, regle, cal)` → `{ applicable: false } | { applicable: true; dateLimite: string | null; rappel: string | null; cartes: readonly ('saisir_delai_statuts' | 'convocation_tardive' | 'assemblee_trop_proche')[]; premiereDatePossible: string | null }` ; assemblée trop proche = `aujourdhui` déjà après la date limite, première date possible = `aujourdhui + délai` ;
   - rappel = `dateLimite − joursAvantRappel`, puis reculé jour par jour tant que `!cal.estOuvre` (jamais après la date visée) ;
   - `deplacerAssemblee(ancienne, nouvelle)` → `{ ancienneDate; nouvelleDate }` pour le journal (aucune mutation).
2. Tests nommés (délai INVENTÉ 15 jours calendaires et rappel 3 jours comme la spec ; calendrier de test avec `Date.UTC`, samedi et dimanche non ouvrés) : `c1-date-limite-15-06-2027`, `c1-rappel-samedi-avance-au-vendredi-11-06-2027`, `c1-envoi-le-20-06-carte-tardive`, `statuts-sans-delai-aucune-date-et-carte`, `statuts-avec-delai-saisi`, `associe-unique-non-applicable`, `assemblee-trop-proche-premiere-date-possible`, `decompte-inconnu-refuse`.

## Hors périmètre
Pas de jours fériés en dur (le calendrier injecté les connaît). Pas de PV ni d'assemblée (spec 03/10, autre lot). Pas de texte de carte (L14-T25).

## Pièges
Règles du noyau comme L14-T02. garde:litteraux : aucun nombre sur une ligne qui nomme le délai. La boucle de recul doit s'arrêter : refus `calendrier_sans_jour_ouvre` après `maxRecul` jours non ouvrés de suite (`maxRecul` est un argument de `RegleConvocation`, jamais en dur). Cas limites exigés : délai NaN, négatif, non entier ou Infinity ; `delaiStatutsJours` à 0 (accepté : date limite = date d'assemblée) ; envoi le jour même de la date limite (pas tardif) ; date d'assemblée mal formée ; forme présente dans deux listes (refus `regle_ambigue`) ; forme dans aucune liste (refus `forme_inconnue`).
