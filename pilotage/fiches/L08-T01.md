## Contexte
Spec 08, fichier 07 : la société cliente est responsable ; son administrateur traite les demandes des personnes (accès, rectification, effacement, limitation, portabilité, opposition) depuis un écran ; table `demande_personne` (societe_id, type, recue_le, echeance, etat, traitee_par, traitee_le, fichier_reponse_empreinte, motif_refus, source_motif) ; geste « Oublier » sur une préférence du chat ; tout geste laisse une ligne au journal chaîné (`personne.demande_recue`, `personne.acces_produit`, `personne.effacement_refuse`, …), sans le contenu de la demande. Toutes les fiches de `packages/noyau/src/rgpd/` (L08-T22 à L08-T31) s'appuient sur ce fichier, SEUL fichier partagé du dossier.
