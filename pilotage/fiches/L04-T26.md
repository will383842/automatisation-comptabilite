## Contexte
Spec 04, fichier 07 §3 : « Nom : AAAA-MM-JJ_FOURNISSEUR_NUMERO_MONTANT-TTC(DEVISE), par ex. 2026-10-14_FOURNISSEUR-EXEMPLE_F-0101_1200.00(EUR) ; caractères hors [A-Z0-9-_.()] retirés ; 180 caractères au plus. Recalculé après correction d'un champ […]. Nom d'origine différent du contenu (date ou montant dans le nom qui ne correspond pas) : signalé. Rangement virtuel : année/mois/fournisseur calculé depuis les champs. »

## À faire
1. `packages/noyau/src/pieces/classement/nom.ts` :
   - `montantPourNom(c: Centimes)` → `"1200.00"`, `"-120.00"`, `"0.05"` par opérations sur la chaîne des centimes (aucune division) ;
   - `segment(texte)` : NFD sans accents, majuscules, blancs → `-`, retrait de tout caractère hors `[A-Z0-9-_.()]`, tirets répétés réduits ;
   - `nomNormalise({ datePiece?, fournisseur?, numero?, ttc?, devise? }, longueurMax)` : champs absents remplacés par `SANS-DATE`, `SANS-FOURNISSEUR`, `SANS-NUMERO`, `SANS-MONTANT`, devise absente `XXX` ; coupe le segment fournisseur (jamais la date ni le montant) pour tenir dans `longueurMax` ; `longueurMax` entier < 40 = `ErreurPiece('reglage_invalide')` ;
   - `cheminVirtuel({ datePiece?, fournisseur? })` → `AAAA/MM/FOURNISSEUR` ou `sans-date/FOURNISSEUR` ;
   - `nomOrigineIncoherent(nomOrigine, { datePiece?, ttc? })` : vrai si le nom d'origine contient une date `AAAA-MM-JJ`, `AAAAMMJJ` ou `JJ-MM-AAAA` différente de `datePiece`, ou un montant `1234.56` / `1234,56` différent du TTC.
2. Tests nommés : `nom-exemple-de-la-spec`, `accents-et-espaces`, `caracteres-interdits-retires` (`/`, `\`, `:`, `*`, emoji), `champs-absents`, `longueur-max-coupe-le-fournisseur`, `montants-negatif-et-petit`, `chemin-virtuel`, `nom-origine-incoherent`.

## Hors périmètre
Renommage journalisé (`avant`, `apres`) : journal chaîné (L04-T51, bloquée).

## Pièges
Les dates d'exemple seulement dans les tests (garde L01-T02). Règles du noyau comme L04-T00.
