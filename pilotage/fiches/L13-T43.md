## Contexte
Spec 13, fichier 05, R13 (V1) : une ligne de classe 6 ou 7 peut être ventilée sur des sections d'un axe, par poids ou par montants ; somme des parts = montant de la ligne au centime ; répartition au plus fort reste. R15 : changer une ventilation après validation crée une nouvelle version, l'ancienne est gardée. Cas limites : section inactive refusée ; période verrouillée : nouvelle version permise et tracée. Tests MOT81-1 (1 000,01 en 3 parts égales : 333,34 / 333,34 / 333,33) et MOT81-3 (700,00 sur une ligne de 800,00 : refusé).

## À faire
1. `packages/noyau/src/analytique/ventilation.ts` (`repartir` du module argent) :
   - `ventilerParPoids(ligne { id; compte; montant }, parts { sectionId; poids }[], sections { id; actif }[])` ;
   - `ventilerParMontants(ligne, parts { sectionId; montant }[], sections)` : somme différente du montant : `ErreurAnalytique('somme_differente')` ;
   - compte hors classes 6 et 7 : `classe_non_ventilable` ; section inconnue ou inactive : `section_inactive` ; section en double : `section_en_double` ;
   - `ajouterVersion(historique, ventilation, date)` : nouvelle liste, version suivante, rien de modifié.
2. Tests nommés : `trois-parts-egales-plus-fort-reste` (MOT81-1, 100 001 centimes), `montants-somme-differente-refusee` (MOT81-3), `classe-non-ventilable` (compte de classe 4), `section-inactive-refusee`, `nouvelle-version-ancienne-gardee`, `ligne-negative` (avoir : parts négatives, somme exacte), `entrees-invalides` (poids NaN, 1,5, négatif, tous nuls).
