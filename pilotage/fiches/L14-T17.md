## Contexte
Spec 14, `01` partie A (DEC-002). Règle 2 : `regle_au_jour(cle, pays, date)` est une fonction pure : même entrée, même sortie, avec `parametre_id` et `version_paquet` ; aucun appel à l'horloge ni à un modèle. Règle 3 : rejouer une écriture validée utilise la version ENREGISTRÉE, pas la dernière ; une version plus récente ne produit qu'une proposition en brouillon. Règle 5 : statut autre que `valide` = la règle s'applique, l'écran affiche « à vérifier ». `parametreAuJour` (L01-T14, `packages/parametres/src/au-jour.ts`) existe déjà : fin exclue, absent ou ambigu = erreur, aucune valeur par défaut. Tests R1 et R2.

## À faire
1. `packages/parametres/src/paquet.ts` (importe `parametreAuJour`, `ParametreLegal`, `ErreurParametre` de `./au-jour.js` sans modifier ce fichier ; classe locale `ErreurPaquet`) :
   - `PaquetParametres { version: string; lignes: readonly ParametreLegal[] }` ;
   - `identifiantParametre(ligne)` → `${cle}|${pays}|${effet_debut}` (stable, sans horloge ni hasard) ;
   - `regleAuJour(paquet, cle, pays, date)` → `{ ligne; parametreId; versionPaquet; aVerifier: boolean }` (`aVerifier` = statut différent de `valide`) ;
   - `UtilisationParametre { ecritureId; parametreId; versionPaquet; dateReference }` ;
   - `rejouer(utilisation, paquets: readonly PaquetParametres[])` → ligne de la version enregistrée ; version absente = refus `version_inconnue` (jamais de repli sur la dernière) ;
   - `comparerAvecDerniere(utilisation, paquets)` → `{ identique: true } | { identique: false; proposition: 'brouillon'; ancienne; nouvelle }`.
2. Tests nommés (taux de test INVENTÉS de la spec : 2 000 jusqu'au 31/12/2026, 2 100 points de base dès le 01/01/2027 ; vente de 100 000 centimes) : `r1-31-decembre-ancienne-valeur`, `r1-1er-janvier-nouvelle-valeur`, `r1-version-du-paquet-portee`, `r2-rejeu-2027-garde-la-version-2026`, `version-inconnue-refusee`, `nouvelle-version-seulement-proposee-en-brouillon`, `statut-non-valide-a-verifier`, `meme-entree-meme-sortie` (deux appels, résultats égaux en profondeur).

Pas de persistance de `utilisation_parametre` ni de refus de validation en base (L14-T34, bloquée). Pas de pays (L14-T18). Ne pas modifier `au-jour.ts` ni `index.ts` du paquet.
