## Contexte
Spec 13, fichier 03, R09 : annexe simplifiée générée avec les rubriques de son millésime, chaque rubrique « à vérifier » tant que le paquet du millésime n'a pas de source officielle citée avec date et contrôle croisé. R10 : la dispense d'annexe tombe quand 2 des 3 seuils (total de bilan, chiffre d'affaires net, effectif) sont dépassés ; le nombre d'exercices consécutifs exigé est à vérifier ; seuils = paramètres datés `a_verifier`. Tests MOT43-1 à MOT43-3 (valeurs de test visiblement fictives : 111 111,00 ; 222 222,00 ; 3).

## À faire
1. `packages/noyau/src/etats/annexe-simplifiee.ts` :
   - `dispenseAnnexe(societe { totalBilan; chiffreAffaires; effectif }, seuils { totalBilan; chiffreAffaires; effectif; statut (non_verifie, a_verifier, valide) })` donne `{ dispense; depasses: liste triée parmi total_bilan, chiffre_affaires, effectif; aVerifier }` ; « dépassé » = strictement supérieur ; `aVerifier` vrai sauf statut `valide` ; effectif entier sûr ≥ 0, montants en centimes, sinon `ErreurAnnexe('entree_invalide')` ;
   - `rubriquesAnnexe(millesime { rubriques: string[]; statutSource })` donne `{ code; aVerifier }[]` dans l'ordre reçu ; liste vide : `millesime_vide` ; code en double : `rubrique_en_double`.
2. Tests nommés (valeurs de MOT43, en centimes) : `aucun-seuil-depasse-dispense` (MOT43-1), `deux-seuils-depasses-annexe` (MOT43-2), `un-seul-seuil-dispense-maintenue` (MOT43-3), `egal-au-seuil-non-depasse`, `effectif-invalide` (NaN, −1, 1,5, Infinity), `seuils-non-valides-a-verifier`, `rubriques-toutes-a-verifier` (6 rubriques), `millesime-vide-ou-double-refuse`.
