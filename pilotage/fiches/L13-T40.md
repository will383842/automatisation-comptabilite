## Contexte
Spec 13, fichier 03, R14 (V1) : par associé, solde du compte courant = somme de lignes justifiées, chacune liée à une écriture, une pièce ou une ligne bancaire ; une ligne sans lien est « non expliquée » et l'écart est la somme de ces lignes. Solde débiteur : alerte et geste G07. Tests MOT63-1 (1 250,00 expliqués sur 1 250,00), MOT63-2 (retrait de 300,00 sans écriture : écart 300,00) et MOT63-3 (débiteur de 200,00 : G07).

## À faire
1. `packages/noyau/src/associes/compte-courant.ts` :
   - `croiserCompteCourant(lignes { id; montant (convention crédit moins débit : positif = dû à l'associé); lien? { type (ecriture, piece, ligne_bancaire); id } }[])` donne `{ solde; explique; nonExplique; lignesNonExpliquees (ids triés); debiteur; gesteRequis? (G07) }` ;
   - lien avec un id vide : non expliqué ; id de ligne en double : `ErreurCompteCourant('ligne_en_double')`.
2. Tests nommés : `tout-explique` (MOT63-1), `retrait-sans-ecriture-non-explique` (MOT63-2), `solde-debiteur-g07` (MOT63-3), `lien-a-id-vide-non-explique`, `ligne-en-double-refusee`, `entrees-invalides` (NaN, 1,5, Infinity ; liste vide : solde 0, rien à expliquer).
