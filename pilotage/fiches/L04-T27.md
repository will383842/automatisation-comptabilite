## Contexte
Spec 04, fichier 06 §3 : « Une pièce lue dont tous les champs critiques sont sur et dont le type est compté donne une proposition ; le moteur la crée en brouillon puis propose. Ce lot ne valide jamais une écriture. » Idempotence : clé = empreinte de la pièce + type (MOT-016). Pièce `plusieurs_factures`, non comptée, sensible ou sous le seuil = aucune proposition. Exemple de la spec : HT 100,00 / 50,00 / 200,00 aux trois taux, TTC 400,50 → D charge 350,00 ; D TVA 5,50 + 5,00 + 40,00 ; C fournisseur 400,50. Les comptes sont des ARGUMENTS (le choix est au moteur).

## À faire
1. `packages/noyau/src/pieces/classement/proposition.ts` :
   - `PiecePourProposition { id; sha256; type: TypePiece; comptee: boolean; sensible: boolean; classementAutomatiquePermis: boolean; aVerifier: MotifAVerifier[]; date: string; journal: string; parTaux: { tauxPdb: number; ht: Centimes; tva: Centimes }[]; ttc: Centimes }` ;
   - `proposerEcriture(piece, comptes: { charge: string; tvaDeductible: string; fournisseur: string })` → `{ ecriture: Ecriture; cleIdempotence: string }` ou `{ aucune: 'non_comptee' | 'sensible' | 'sous_le_seuil' | 'a_verifier' | 'plusieurs_factures' | 'desequilibre' | 'vide' }` ;
   - écriture au statut `brouillon` (type `Ecriture` de `../../ecritures/modele.js`, L01-T06) : D charge = Σ HT ; une ligne D TVA par taux dont la TVA est non nulle (libellé = `tva@<pdb>`) ; C fournisseur = TTC ; avoir (TTC négatif) = sens inversés sur les valeurs absolues ;
   - l'écriture doit passer `verifierEcriture` (L01-T06) : sinon `aucune: 'desequilibre'` (jamais d'exception vers l'appelant) ;
   - `cleIdempotence` = `${sha256}:${type}`.
2. Tests nommés : `facture-un-taux` (taux inventé de 1 900 pdb : 1 000,00 + 190,00 = 1 190,00), `facture-trois-taux-inventes` (mêmes valeurs que L04-T16 : D charge 350,00, D TVA 6,00 + 5,50 + 38,00, C 399,50), `avoir-sens-inverses`, `taux-a-tva-nulle-sans-ligne`, `non-comptee-aucune`, `sensible-aucune`, `sous-le-seuil-aucune`, `desequilibre-aucune` (Σ HT + Σ TVA ≠ TTC), `meme-piece-meme-cle`.
