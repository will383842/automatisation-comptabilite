## Contexte
Textes rendus à partir des CODES du noyau. Spec 14 : `02` A (« TVA bloquée : N pièces à lever », « montant à confirmer », payée : « par qui, quand ») ; `01` B (bandeau « règles possiblement périmées : à vérifier ») ; `01` C (« établissement fermé : vérifiez » ; service en panne : saisie à la main) ; `01` E (connecteur dégradé avec la conduite à tenir : saisie à la main, réessayer demain) ; `02` C (interrupteur « inclure le sous réserve » visible et verrouillé ; refus) ; `04` A (une raison en mots simples par ligne non sûre).

## À faire
1. `packages/textes/src/documents/sources-validation.ts` : `export const sourcesValidation = { … } as const` avec :
   - `tva` : `bloquee: (n: number) => …` (singulier pour 1, pluriel sinon : « 1 pièce à lever », « 2 pièces à lever »), `aConfirmer`, `payee: (par: string, le: string) => …`, `interrupteurSousReserve` (libellé) et `interrupteurVerrouille` (explication courte) ;
   - `veille.reglesPossiblementPerimees` ; `sirene.etablissementFerme`, `sirene.saisieManuelle` ; `connecteurs.degrade`, `connecteurs.enPanne` ;
   - `casSur` : une phrase par code de raison de L14-T22 (`nature_jamais_sure`, `lecture_douteuse`, `fournisseur_peu_valide`, `anomalie_ouverte`, `montant_au_seuil_ou_plus`, `fournisseur_hors_union`, `tva_en_doute`, `compte_absent`).
2. Tests nommés : `tva-bloquee-singulier-et-pluriel`, `tva-bloquee-texte-de-la-spec` (« TVA bloquée : 2 pièces à lever »), `une-raison-par-code-du-cas-sur` (liste des codes écrite dans le test), `aucun-chiffre-estime` (aucun texte ne contient « environ », « estimé », « à peu près »), `vouvoiement`, `aucun-mot-interdit` (liste par morceaux), `bandeau-veille-texte-de-la-spec`.

## Hors périmètre
Ne pas toucher `fr.ts` ni `index.ts`. Textes juridiques : L14-T25.

## Pièges
Aucun texte ne dit que le logiciel paie, dépose ou transmet. `n` NaN, négatif ou non entier : la fonction n'a pas à le corriger, mais le test fixe qu'elle ne lève pas d'exception et rend une chaîne (cas limite exigé) ; 0 pièce : la fonction n'est pas appelée (commentaire), le test fixe quand même le texte rendu.
