## Contexte
Spec 14, `03`, JUR-014. Modèle prérempli depuis les comptes, 6 rubriques : activité ; loyers ; charges (hors intérêts) ; emprunts (capital restant dû, intérêts) ; résultat ; comptes courants. Chaque chiffre renvoie à ses écritures. Les comptes de chaque rubrique sont À VÉRIFIER : ils arrivent en ARGUMENT (table de rubriques), jamais en dur. Règle 3 : le texte contient une fois la phrase « pas de dépôt au greffe pour ce document » et aucune autre mention de dépôt au greffe ; aucun PV. Test S1 : loyers 2 400 000, charges 525 000, intérêts 310 000, capital restant dû 11 840 000, compte courant 1 200 000 centimes : résultat 1 565 000.

## À faire
1. `packages/noyau/src/juridique/rapport-sci.ts` (types `Ecriture`, `LigneEcriture` importés de `../ecritures/modele.js` ; `ajouter`, `soustraire`, `centimes` de `../argent/index.js` ; classe locale `ErreurRapportSci`) :
   - `PosteRubrique { code: string; prefixes: readonly string[]; exclus: readonly string[]; sens: 'debit' | 'credit' }` ; `TableRubriques { loyers: PosteRubrique; charges: PosteRubrique; interets: PosteRubrique; capitalRestantDu: PosteRubrique; comptesCourants: PosteRubrique }` ;
   - `preparerRapportSci(ecritures, table, { activite: string | null })` → `{ rubriques: readonly { code: 'activite' | 'loyers' | 'charges' | 'emprunts' | 'resultat' | 'comptes_courants'; montants: readonly { poste; centimes; sources: readonly { ecritureId; ligneIndex }[] }[] }[]; mentions: readonly ['pas_de_depot_greffe']; pv: null; statut: 'brouillon'; mention: 'prepare_par_ia' }` ; seules les écritures au statut `valide` sont lues ; résultat = loyers − charges − intérêts ;
   - un compte qui correspond à deux postes = refus `compte_dans_deux_postes` (la table est mal faite).
2. Tests nommés (comptes INVENTÉS dans la table du test, montants de S1) : `s1-resultat-1-565-000`, `s1-six-rubriques-dans-l-ordre`, `s1-phrase-du-greffe-une-fois-et-aucun-pv`, `chaque-montant-somme-de-ses-sources` (recalcul à la main depuis les lignes du jeu), `brouillons-ignores`, `compte-dans-deux-postes-refuse`, `activite-absente-rubrique-vide-sans-invention`.
