## Contexte
Spec 14, `01` partie B. Règle 2 : balayage chaque semaine, chaque jour en période rapprochée (paramètre `veille.periode_rapprochee`). Règle 3 : un changement détecté crée une fiche sous un délai (7 jours dans la spec). Règle 5 : dernier balayage trop ancien (8 jours ; 2 en période rapprochée : HYPOTHÈSE) = alerte. Règle 6 : veille en alerte ou paramètre périmé = `depot_automatique_autorise = faux` et bandeau « règles possiblement périmées : à vérifier ». Tests VE1 et VE2. Tous ces nombres sont des ARGUMENTS (D31).

## À faire
1. `packages/noyau/src/sources/veille-etat.ts` (classe locale `ErreurEtatVeille`) :
   - `interface Calendrier { ajouterJours(date: string, n: number): string }`, injecté : aucune arithmétique de date dans ce fichier ;
   - `enPeriodeRapprochee(date, periode: { debutMoisJour: string; finMoisJour: string })` : format MM-JJ ; une période qui passe le 31 décembre (début après fin) est gérée ;
   - `etatVeille({ dernierBalayage: string | null; maintenant; maxJoursNormal; maxJoursRapproche; periode }, cal)` → `'ok' | 'alerte'` : alerte si `cal.ajouterJours(dernierBalayage, max) < maintenant` ; aucun balayage = alerte ;
   - `ficheEnRetard({ detecteeLe; ficheCreeeLe: string | null; maintenant; maxJours }, cal)` → booléen ;
   - `modeDegrade({ etat; parametresPerimes: number })` → `{ depotAutomatiqueAutorise: boolean; bandeau: 'regles_possiblement_perimees' | null }`.
2. Tests nommés (nombres INVENTÉS repris de la spec : 8 et 2 jours, période du 15/12 au 15/01 ; calendrier de test écrit dans le fichier de test avec `Date.UTC`) : `balayage-recent-ok`, `huit-jours-plus-un-alerte`, `periode-rapprochee-plus-stricte`, `periode-qui-passe-le-31-decembre`, `fiche-creee-a-temps`, `fiche-en-retard`, `veille-en-alerte-bloque-le-depot-et-pose-le-bandeau`.

## Pièges
Règles du noyau comme L14-T02. garde:litteraux rougit si une ligne qui nomme délai, durée, seuil ou plafond contient un nombre autre que 0 ou 1 : aucun nombre de jours dans src. Cas limites exigés : `maxJours` NaN, négatif, non entier ou Infinity (refus `nombre_invalide`) ; `maintenant` antérieur au dernier balayage (refus `ordre_inverse`) ; MM-JJ invalide (mois 13, 30 février) ; `parametresPerimes` négatif ou non entier. Égalité exacte à la limite = `ok` (fixé par un test).
