## Contexte
Les routes de lecture du lot (L14-T30, L14-T32) et le faux serveur (L14-T31, L14-T33) servent de futurs écrans sans base réelle. Comme `genererCompta()` (L01-T22), le jeu est déterministe (graine fixe) et 100 % fictif : SIREN fictifs 123456782 (une SARL fictive, « Lemoine Rénovation ») et 987654324 (une SCI fictive, « SCI Fictive des Tilleuls »), personnes « Camille Fictif ». Aucune valeur légale réelle : dates limites et seuils inventés.

## À faire
1. `packages/donnees-fictives/src/juridique.ts` (réutilise `GRAINE`, `creerAlea` par import relatif sans les modifier) : `genererJuridique(graine = GRAINE)` → `{ version: 1; obligations: { exerciceId; societeSiren; forme: 'FORME_A' | 'FORME_SCI'; rapportGestion: { statut: 'dispense' | 'brouillon' | 'non_applicable'; questions: string[] }; convocation: { applicable: boolean; dateAssemblee: string | null; dateLimite: string | null; rappel: string | null; cartes: string[] }; confidentialite: { proposee: boolean; choix: 'non_choisi' | 'demandee' | 'refusee' | null }; cartes: { code; objetId; ecartCentimes: number | null }[]; mention: 'prepare_par_ia' }[] }` : la SARL a un brouillon avec la question `effectif`, une convocation avec rappel, une carte `ecart_montant` de 50 000 ; la SCI : `non_applicable` pour la convocation, aucune proposition de confidentialité, une carte `deposer_convention`.
2. `packages/donnees-fictives/src/sources.ts` : `genererSources(graine = GRAINE)` → `{ version: 1; veille: { etat: 'ok' | 'alerte'; dernierBalayage: string; depotAutomatiqueAutorise: boolean }; connecteurs: { connecteur: string; etat: 'ok' | 'degrade' | 'panne'; dernierOk: string | null }[] }` : connecteurs fictifs `annuaire_entreprises`, `tva_intracom`, `plateforme_agreee` ; un en `degrade`.
3. Tests nommés : `meme-graine-meme-empreinte` (SHA-256 de la sérialisation, figé), `deux-societes-siren-fictifs`, `sci-sans-convocation-ni-confidentialite`, `sarl-question-effectif`, `ecart-50-000`, `veille-en-alerte-depot-interdit` (si `etat = alerte`, `depotAutomatiqueAutorise` est faux), `option-vide-listes-vides` (second argument `{ vide: true }` des deux générateurs : listes vides), `aucun-mot-interdit` (liste par morceaux).

## Hors périmètre
Pas de route, pas de handler. Ne pas toucher `compta.ts`, `generateur.ts` ni `index.ts`.

## Pièges
garde:fictif contrôle e-mails et IBAN : aucun des deux ici. Aucun nom de vraie société, aucun vrai nom de connecteur commercial. Cas limites exigés : graine 0 et graine négative (déterministes), sérialisation stable (clés triées), dates en AAAA-MM-JJ valides (test de forme).
