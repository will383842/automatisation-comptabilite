## Contexte
Spec 02, fichier 02, règle 6 : « 4 modes reconnus (colonne signée, débit/crédit, colonne sens D/C, suffixe « 123,45- »). » Profil : `decimal`, `milliers`. Test T02-2 : « 1.234,56- » → −123 456 centimes. Cas limites : « N/A » ou cellule vide. Montant = centimes entiers, jamais un `number` décimal (eslint du noyau).

## À faire
1. `packages/noyau/src/banque/import/montants.ts` :
   - `lireMontant(texte: string, format: { decimal: ',' | '.'; milliers: '' | ' ' | '.' | ',' | "'" })` → `Centimes` : lecture caractère par caractère (aucun `parseFloat`, aucun `Number()` sur un texte décimal) ; espaces insécables acceptés comme milliers ; 0, 1 ou 2 chiffres après la virgule (3 et plus : `trop_de_decimales`) ; signe `-` devant, `-` en suffixe, parenthèses `(12,00)` = négatif ; `+` accepté ;
   - `montantSigne(cellules, mode)` avec `mode` : `{ type: 'signe'; colonne }`, `{ type: 'debit_credit'; debit; credit }` (une seule des deux remplie, sinon `deux_sens` ; aucune : `aucun_montant`), `{ type: 'sens_dc'; montant; sens; debit: string; credit: string }`, `{ type: 'suffixe_moins'; colonne }` ;
   - classe locale `ErreurMontant` : `vide`, `non_numerique`, `trop_de_decimales`, `deux_sens`, `aucun_montant`, `hors_limites` (au-delà de l'entier sûr), `format_ambigu` (même caractère pour décimale et milliers).
2. Tests nommés : `virgule-et-point-milliers` (`1.234,56` → 123 456), `point-decimal-et-virgule-milliers`, `suffixe-moins` (T02-2 : −123 456), `parentheses-negatif`, `debit-credit`, `sens-d-c`, `vide-et-na-refuses` (`''`, `N/A`, `-`, `,`), `trop-de-decimales-refuse` (`1,234` en mode décimale virgule sans milliers), `hors-limites-refuse` (`99999999999999999,99`).

## Hors périmètre
Devises et conversion (L02-T39, T40). Lecture des colonnes d'un fichier (L02-T15).

## Pièges
Cas limites exigés : `1e5`, `Infinity`, `NaN` en texte (tous `non_numerique`), `0,00` (vaut 0, accepté), `-0,00` (vaut 0, jamais `-0` : test `Object.is(x, 0)`), double signe `--1`, espace en tête et en queue. Règles du noyau (ni `/`, ni `parseFloat`, ni littéral décimal). Sensible (argent).
