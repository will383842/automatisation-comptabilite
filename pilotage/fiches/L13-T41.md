## Contexte
Spec 13, fichier 04, R16 (V1) : appel lu D 646000 / C 431000 ; paiement D 431000 / C 512000 ; régularisation = écriture de différence. Les échéances sont les dates lues sur l'appel, jamais calculées ; sans date lue : « date à vérifier ». Tests MOT82-1 (appel de 1 800,00 échéant le 05/12/2026) et MOT82-2 (régularisation +250,00 puis −100,00).
