## Contexte
Spec 14, `01` partie C (DEC-012). Règle 1 : quota `sirene.quota_par_minute` (30 dans la spec, À VÉRIFIER), usage visé 80 % (24 par minute). Règle 2 : la file attend, ne perd rien, ne dépasse jamais le quota sur une fenêtre glissante de 60 s. Test S1 : 1 000 SIREN fictifs, lot de taille 1, horloge simulée : au plus 30 requêtes sur toute fenêtre de 60 s, 42 minutes simulées au plus, 0 perdu. Le quota, la fenêtre et l'intervalle sont des ARGUMENTS.

## À faire
1. `packages/noyau/src/sources/sirene-planif.ts` (classe locale `ErreurPlanif`) :
   - `OptionsQuota { quotaParFenetre: number; fenetreMs: number; intervalleMinMs: number; tailleLot: number }` (l'intervalle remplace « 80 % » : aucune division ici) ;
   - `peutEnvoyer(envoisPasses: readonly number[], maintenant, o)` : vrai si moins de `quotaParFenetre` envois dans `]maintenant − fenetreMs, maintenant]` et si le dernier envoi date d'au moins `intervalleMinMs` ;
   - `planifier(demandes: readonly string[], debut: number, o)` → `{ lot: string[]; a: number }[]` : découpe en lots de `tailleLot` dans l'ordre d'arrivée, puis donne à chaque lot le premier instant permis ; aucune demande perdue ni dupliquée ;
   - `respecteLeQuota(instants, o)` : vérifie toute fenêtre glissante (sert aux tests et au futur client réel).
2. Tests nommés (valeurs de la spec, données de test INVENTÉES : SIREN fictifs générés avec une clé de Luhn valide) : `mille-siren-jamais-plus-de-trente-par-fenetre`, `mille-siren-en-quarante-deux-minutes-au-plus`, `aucune-demande-perdue-ni-doublee`, `ordre-d-arrivee-garde`, `lots-de-vingt`, `file-vide-aucun-envoi`, `peut-envoyer-a-la-limite-exacte`.

## Hors périmètre
Pas de partage entre clients (L14-T05), pas de cache (L14-T06), aucun appel réseau (L14-T37, bloquée).

## Pièges
Règles du noyau comme L14-T02 ; aucune lecture de l'horloge (`Date.now` interdit ici : l'instant est un argument). garde:litteraux : ne pas écrire de nombre sur une ligne qui nomme un délai ou une durée. Cas limites exigés : options NaN, Infinity, négatives, nulles ou non entières (refus `option_invalide`) ; `envoisPasses` non triés (même résultat) ; instants dans le futur de `maintenant` (refus `ordre_inverse`) ; un seul SIREN ; `tailleLot` plus grand que la file.
