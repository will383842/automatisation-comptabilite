## Contexte
Spec 15, PR-R7 (point P4 : on dit « pseudonymisée », jamais « anonymisée »). Champs acceptés UNIQUEMENT : `type` (liste blanche d'environ 30 codes), `ecran_code`, `duree_ms`, `appareil` (`bureau`, `mobile`), `version_app`, `horodatage`. Un champ hors liste : 400 `champ_inconnu` et l'événement est jeté. Jamais stocké : texte saisi ou cherché, montant, nom, e-mail, IBAN, adresse IP, identifiant de pièce ou d'écriture, agent utilisateur. Personne remplacée par `personne_ref` = HMAC du `personne_id` avec un secret propre au client. Durée humaine bornée (30 minutes dans la spec). Mesure désactivée : rien n'est écrit.

## À faire
1. `usage/usage.ts` :
   - `TYPES_USAGE` (liste gelée : `ecran_ouvert`, `carte_ouverte`, `carte_resolue`, `export_lance`, `recherche_lancee`, `preference_modifiee`, `raccourci_utilise`, `palette_ouverte`… au plus 30) ;
   - `validerEvenements(brut: unknown[], { dureeMaxMs: number })` → `{ acceptes; rejetes: { index; code }[] }` : objet seulement ; toute clé hors des 6 = `champ_inconnu` ; `type` hors liste = `type_inconnu` ; `ecran_code` `^[a-z][a-z0-9]{1,5}$` ; `duree_ms` entier ≥ 0 ou absent, ramené à `dureeMaxMs` s'il le dépasse, non entier ou non fini = `valeur_invalide` ; `horodatage` entier de secondes, de 0 à 99 999 999 999 (au-delà, c'est une valeur en millisecondes : refusée ; non entier : refusé) ; `version_app` `^[0-9]+\.[0-9]+\.[0-9]+$` ;
   - `pseudonyme(personneId, secret)` : HMAC-SHA-256 par `node:crypto`, hexadécimal ; secret vide ou de moins de 32 octets = erreur ;
   - `enregistrer(evenements, { mesure: 'active' | 'desactivee'; reglageInstallation?: 'desactivee' })` → liste à écrire, VIDE si désactivée par la personne ou par l'installation.
2. Tests nommés : `six-champs-acceptes`, `champ-en-trop-rejete` (`texte`, `montant`, `ip`, `email`, `pieceId`), `type-inconnu-rejete`, `duree-ramenee-au-maximum`, `duree-invalide-rejetee` (`-1`, `1.5`, `NaN`, `Infinity`, `'10'`), `horodatage-en-secondes-seulement`, `pseudonyme-stable-et-different-par-secret`, `secret-trop-court-refuse`, `desactivee-rien-ecrit`, `installation-l-emporte`.
