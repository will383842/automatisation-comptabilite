## Contexte
Spec 13, fichier 04, R17 : l'échéancier est calculé depuis les paramètres datés ; chaque échéance garde son paramètre, sa source et son statut ; paramètre non vérifié : date « à vérifier ». Tests MOT73-6 (les 4 dates d'acompte suivent la fenêtre où tombe la clôture ; « le test échoue si les 4 dates restent figées quelle que soit la clôture ») et MOT73-7 (solde : « N-ième mois qui suit la clôture », avec une exception pour une clôture donnée). Le catalogue générique (ancrage, décalage, rappels) est L03-T42 ; les fenêtres de clôture n'y entrent pas.

## À faire
1. `packages/noyau/src/echeances/impot-societes.ts` (`estDateValide`, `ajouterMois`, `finDeMois` de `../dates/civiles.js`) :
   - `acomptesIs(dateCloture, table { fenetres: { debut (MM-JJ); fin (MM-JJ); echeances (MM-JJ)[] }[]; statut })` : trouve la fenêtre qui contient le MM-JJ de la clôture (une fenêtre peut passer le 31/12) ; chaque MM-JJ devient la date de l'année de clôture, ou de l'année précédente si elle tombe après la clôture ; dates triées ; leur ordre doit être celui de la table, sinon `table_incoherente` ; aucune fenêtre : `fenetre_absente` ; deux fenêtres : `table_ambigue` ; donne `{ dates; aVerifier }` ;
   - `soldeIs(dateCloture, regle { moisApres; jour; exceptions: { cloture (MM-JJ); echeance (MM-JJ); decalageAnnees }[]; statut })` : exception si le MM-JJ de clôture y figure ; sinon `ajouterMois(cloture, moisApres)` puis le jour `jour` de ce mois (jour absent du mois : `jour_inexistant`) ;
   - `aVerifier` vrai sauf statut `valide`.
2. Tests nommés (table INVENTÉE : fenêtres 11-10 à 02-09 donnant 02-10, 05-10, 08-10, 11-10 ; 02-10 à 05-09 donnant 05-10, 08-10, 11-10, 02-10 ; 05-10 à 08-09 ; 08-10 à 11-09 ; règle de solde inventée : 3 mois, jour 10, exception 12-31 donne 04-20 de l'année suivante) : `acomptes-cloture-31-decembre` (2027-02-10, 2027-05-10, 2027-08-10, 2027-11-10), `acomptes-cloture-31-mars` (2026-05-10, 2026-08-10, 2026-11-10, 2027-02-10), `table-modifiee-change-le-resultat`, `table-incoherente-refusee`, `fenetre-absente-ou-ambigue`, `solde-cas-general` (clôture 2027-03-31 : 2027-06-10), `solde-exception` (clôture 2026-12-31 : 2027-04-20), `statut-non-valide-a-verifier`, `dates-invalides` (2027-02-30, chaîne vide, 2027-1-1 ; moisApres NaN ou 1,5).
