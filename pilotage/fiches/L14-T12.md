## Contexte
Spec 14, `03`, JUR-009. `option_confidentialite.eligible` est calculé par `jur.confidentialite.conditions` (taille, forme ; À VÉRIFIER) à la date de clôture ; la proposition n'apparaît qu'aux sociétés éligibles et seulement si le dépôt des comptes est proposé (les formes sans dépôt sont exclues par la règle, pas par le code). Jamais cochée par défaut ; le choix est celui du dirigeant, nominatif et daté. Donnée de taille manquante : option non proposée, carte « complétez le bilan et l'effectif ». Le logiciel ne dépose rien. Test K1.

## À faire
1. `packages/noyau/src/juridique/confidentialite.ts` (classe locale `ErreurConfidentialite`) :
   - `ConditionsConfidentialite { formesAdmises: readonly string[]; seuils: { bilanCentimes: number; chiffreAffairesCentimes: number; effectif: number }; maxSeuilsDepasses: number }` ;
   - `optionConfidentialite({ forme; bilanCentimes: number | null; chiffreAffairesCentimes: number | null; effectif: number | null; depotPropose: boolean }, conditions)` → `{ proposee: false; carte: 'completer_bilan_effectif' | null } | { proposee: true; choix: 'non_choisi' }` ;
   - `choisir(option, { choix: 'demandee' | 'refusee'; par: string; le: string })` → `{ choix; choisiPar; choisiLe }` ; refus `option_non_proposee` si l'option n'est pas proposée, refus `auteur_absent` si `par` est vide.
2. Tests nommés (seuils INVENTÉS ; formes fictives `FORME_A`, `FORME_B` dans le test) : `k1-eligible-proposee-non-cochee`, `k1-forme-non-admise-aucune-proposition`, `k1-au-dessus-du-seuil-aucune-proposition`, `depot-non-propose-aucune-proposition`, `donnee-manquante-carte-completer`, `choix-nominatif-et-date`.
