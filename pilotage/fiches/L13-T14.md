## Contexte
Spec 13, fichier 03, R11 : frais et commissions en 627000 ; virement interne en 580000, soldé à 0,00 entre deux comptes. Tests MOT55-3 (« FRAIS TENUE DE COMPTE » 12,50 : D 627000 / C 512000, BROUILLON, source citée) et MOT55-4 (virement de 500,00 de BQ1 vers BQ2 : deux écritures, 580000 = 0,00). Cas limite : virement interne dont une jambe manque : 580000 non soldé.

## À faire
1. `packages/noyau/src/banque/propositions.ts` (type `Ecriture` de `../ecritures/modele.js`) :
   - `proposerFrais({ id; date; journal; libelle; montant; ligneBancaireId }, comptes { frais; banque })` donne une écriture `brouillon` D frais / C banque, avec la ligne bancaire en source ;
   - `proposerVirementInterne({ idSortie; idEntree; date; journal; montant }, comptes { attente; banqueSource; banqueCible })` donne deux écritures `brouillon` : D attente / C banqueSource, puis D banqueCible / C attente ;
   - `soldeAttente(ecritures, compteAttente)` donne débits moins crédits (centimes) ;
   - montant nul ou négatif : `ErreurBanque('montant_invalide')` ; banque source = banque cible : `meme_compte`.
2. Tests nommés (comptes passés en argument : 627000, 512000, 580000 ; montants inventés) : `frais-tenue-de-compte` (1 250), `virement-interne-deux-ecritures` (50 000), `attente-soldee-a-zero`, `jambe-manquante-attente-non-soldee`, `montant-nul-ou-negatif-refuse` (0, −1, NaN, 1,5), `meme-compte-refuse`, `ecritures-equilibrees` (chaque écriture passe `verifierEcriture` de L01-T06).

## Hors périmètre
Rapprochement, opérations sans pièce, encaissements clients et paiements fournisseurs : lot banque (spec 02).

## Pièges
Jamais de statut `valide` en sortie (R04 de la spec 13, fichier 01). Aucun numéro de compte en dur dans `src`. Règles du noyau comme L01-T06. Sensible (argent).
