## Contexte
Spec 14, `02` partie A : la carte montre le montant de la déclaration validée, ou « montant à confirmer », ou « TVA bloquée : N pièces à lever » avec le lien vers elles (aucun montant), ou l'état payé (qui, quand). Le logiciel ne paie jamais. L'état arrive déjà calculé par `carteTva` (L14-T19) ; les textes arrivent en props (L14-T26) ; le montant passe par le composant `Montant` (L01-T31).

## À faire
1. `packages/ui/src/composants/CarteTvaAPayer.tsx` :
   - props `{ etat: { etat: 'montant'; centimes: number } | { etat: 'a_confirmer' } | { etat: 'bloquee'; pieces: number } | { etat: 'payee'; par: string; le: string }; echeance: string; textes: { titre; aConfirmer; bloquee: string; payee: string; lienPieces: string; echeance: string }; lienPieces: string }` (type d'état recopié, sans import du noyau : `packages/ui` n'en dépend pas) ;
   - réutilise `Carte` (L01-T29) et `Montant` (L01-T31) ; état `bloquee` : AUCUN élément `Montant` rendu, un lien vers `lienPieces` ; état `a_confirmer` : aucun chiffre ;
   - aucun bouton « payer ».
2. `carte-tva.css` : variables de `jetons.css` seulement.
3. Tests nommés : `montant-affiche-via-montant`, `a-confirmer-aucun-chiffre`, `bloquee-aucun-montant-et-lien`, `payee-par-et-date`, `aucun-bouton-payer`, `echeance-affichee`, `montant-negatif-credit-affiche` (crédit de TVA rendu par `Montant`).

## Hors périmètre
Pas d'écran : la carte sera posée sur le tableau de bord et sur E19 par leurs propres fiches (E19 appartient au lot 03). Ne pas toucher `packages/ui/src/index.ts`.

## Pièges
« Aucun chiffre » se teste par l'absence de tout caractère 0 à 9 dans la carte quand l'état est `a_confirmer` ou `bloquee` (hors date d'échéance : la tester dans un élément séparé). Cas limites exigés : `pieces` à 1 (texte reçu tel quel), `lienPieces` vide (lien non rendu, pas de lien vide), textes vides.
