## Contexte
Spec 05, fichier 03 §3 : les étapes sont visibles au fil du tour, tirées des appels réels, jamais la chaîne de pensée. Fichier 06 §3 : chaque chiffre affiché porte une source cliquable ; référence inconnue = « je ne sais pas » ; chiffre en dur retiré = « voir la source ».

## À faire
1. `Etapes.tsx` : `{ etapes: { libelle; etat: 'en_cours' | 'faite' | 'echec' }[]; titre }` ; liste ordonnée ; `aria-live="polite"` ; état par icône ET texte (jamais la couleur seule).
2. `TexteSources.tsx` : `{ segments: Segment[]; libelles: { inconnu; voirSource; lexique }; onSource(source) }` où `Segment` reprend la forme de L05-T18 (déclarée localement, comparée par un test de type si L05-T18 est fusionnée) ; montant formaté par `Montant` (L01-T31), date par `affichage.ts` ; chaque valeur est un bouton qui appelle `onSource` ; marqueurs `⟦voir_source⟧` et `⟦lexique⟧` de L05-T19 remplacés par leur libellé.
3. Tests nommés : `etapes-dans-l-ordre`, `etat-annonce-sans-couleur-seule`, `liste-vide`, `segment-texte`, `montant-formate-et-cliquable`, `date-formatee`, `inconnu-je-ne-sais-pas`, `marqueur-voir-source`, `valeur-invalide` (NaN, Infinity, montant non entier : affichée comme inconnue, jamais « NaN »), `aucun-html-interprete` (un segment texte `<b>x</b>` s'affiche tel quel).
