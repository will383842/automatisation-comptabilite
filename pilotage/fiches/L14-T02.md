## Contexte
Spec 14, `01` partie B (DEC-003). `fiche_changement` : statut parmi detectee, resumee, validee, testee, signee, publiee, rejetee. Règle 3 : l'IA ne fait que résumer ; elle ne modifie aucun paramètre. Règle 4 : un état ne saute jamais l'état précédent ; la validation est faite par une personne. La veille est commune à Axion et ne contient aucune donnée client.

## À faire
1. `packages/noyau/src/sources/veille-circuit.ts` (classe locale `ErreurVeille` avec un champ `code`) :
   - types `StatutFiche`, `Acteur = { type: 'personne' | 'ia'; id: string }`, `FicheChangement { id; sourceId; detecteeLe; empreinteAvant; empreinteApres; resumeIa: string | null; statut; parametresTouches: readonly string[]; validateur: string | null; paquetId: string | null; historique: readonly { de; vers; par; le }[] }` ;
   - `creerFiche({ id, sourceId, detecteeLe, empreinteAvant, empreinteApres })` : refus `empreintes_identiques` si avant = après ;
   - `avancer(fiche, action, acteur, le, donnees?)` → NOUVELLE fiche (l'entrée n'est jamais modifiée) ; actions `resumer` (seule action permise à l'IA ; remplit `resumeIa`), `valider` (personne ; remplit `validateur` et `parametresTouches`), `tester`, `signer`, `publier` (exige `paquetId`), `rejeter` (personne, depuis tout état sauf `publiee` et `rejetee`) ; transition hors ordre = `transition_interdite` ; IA sur une autre action = `ia_non_autorisee` ; `le` antérieur au dernier pas de l'historique = `date_anterieure`.
2. Tests nommés : `circuit-complet-dans-l-ordre`, `saut-d-etat-refuse` (detectee vers validee), `ia-ne-valide-pas`, `ia-ne-touche-aucun-parametre` (IA + `valider` avec `parametresTouches` : refus, fiche inchangée), `rejet-depuis-resumee`, `rejet-apres-publication-refuse`, `publier-sans-paquet-refuse`, `entree-jamais-modifiee` (entrée gelée en profondeur par `Object.freeze`).
